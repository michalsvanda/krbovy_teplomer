<https://www.printables.com/model/711587-esp32-wroom-32-usb-c-box-with-lid>

Šíří se pod licencí původního díla, [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/). Jsou zde uložené proto, aby šlo upravené modely znovu vygenerovat skriptem `../build_enclosure.py`.
